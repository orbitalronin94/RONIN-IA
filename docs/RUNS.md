# Libro de ejecuciones (runs) de RONIN-IA

Registro cronológico de GitHub Actions. Cada entrada enlaza al run original, registra el estado, el commit y la finalidad de la ejecución. Los detalles numéricos, logs y artefactos están en la página enlazada.

**Regla operativa:** los workflows registrados actualizan este libro automáticamente al terminar, tanto si acaban en éxito como en fallo o cancelación. Cada resumen de workflow enlaza directamente aquí. El historial es append-only: las correcciones se añaden como nuevas entradas y no se borran resultados anteriores.

La cobertura automática incluye CI, entrenamiento oficial y reducido, preparación del corpus Portfolio, auditoría de corpus y biblioteca criptográfica, calibración REF, benchmark inicial, ciclos sintéticos, auditoría Supra, generación de candidatos Phi-4, caché de tutores, comparativa A/B, validación de manifiestos e ingesta de muestras externas.

## Formato obligatorio para nuevas entradas

El registrador automático añade fecha UTC, nombre del workflow, número y URL del run, resultado, rama, commit, evento disparador y resumen de la finalidad del workflow. Para los runs que producen artefactos, la URL del run permite acceder a los informes y archivos publicados.

Si una ejecución cambia datos, código o documentación, la descripción debe identificar el artefacto o commit correspondiente. Un run fallido también se registra: el fallo forma parte de la trazabilidad experimental.
