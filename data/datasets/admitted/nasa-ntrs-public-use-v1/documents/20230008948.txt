Overview





PCRT uses resonant frequency – the natural frequency where a medium vibrates at the highest amplitude. PCRT measures the resonance frequencies of whole parts and compares the results to parts of the same type that are known to be nominal. 


Off-nominal properties or defects in a part will affect its resonant frequency. This technology is an especially important technology as additive manufactured parts become more prevalent. 





The nondestructive evaluation (NDE) of additively manufactured parts presents unique challenges and opportunities. Additive manufacturing (AM) technology enables complex part geometries and morphologies, which test the limits of conventional NDE techniques. PCRT can potentially detect common AM defects such as porosity, lack of fusion, inclusions, oxides/corrosion, etc.

How does PCRT work?


Set Up


Sending/Receiving transducers must be in contact with the part


Transducers sweep over a range of frequencies to identify resonant modes


Fixture & Transducer set-up must remain consistent with each specimen


Channels must be in the same pattern 


Hardware Verification Test can give a red/green light to indicate if the fixture is correctly set up





Analysis


Vibrant – the company that developed this system – has pattern recognition software to provide pass/fail analysis.


There are three main methods of analysis Vibrant uses:


Z-score Analysis


Characterizes part resonances relative to a reference population


Identifies Gross Outliers


Vibrational Pattern Recognition (VIPR)


Uses Mahalanobis-Taguchi System (MTS) 


Part-to-Itself (PTI)


Metrics describe how a part changes due to processing operations (e.g. heat treated)





Process Sensitivities 


Consistent part geometry is critical


Failed AM builds can result in incorrect height or shape


Messy build plate removal can result in incorrect shape


Changing build parameters will invalidate previous population

















AM Dogbone Samples


Tensile test remnants are machined down for consistent size and shape


Parts are PCRT tested to determine if PCRT analysis aligns with mechanical test notes, which already determined if the build was good or bad. 


Initial PCRT analysis (Z-score) shows distinctions between builds with outliers present. 


Analysis showed PCRT capability to compensate for variables such as mass, height, and diameter to find true outliers
