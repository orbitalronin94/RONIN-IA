<p>Introduction: Setting
</p>
<p>• Example: Network of spacecraft, satellites, or control stations that each have 
</p>
<p>computing power and can communicate
</p>
<p>• Distributed graph algorithms: Answer some question about a graph whose nodes 
</p>
<p>are the processors, where each node has local information </p>
<p></p>
</div>
<div class="page"><p></p>
<p>• CONGEST-CLIQUE Model:
</p>
<p>1. Computation happens in rounds 
</p>
<p>-(compute, communicate, compute, …)
</p>
<p>2. Congested: Communication limited by 
</p>
<p>message size O(log(n)) bits, 
</p>
<p>n being the number of nodes in the graph
</p>
<p>→one message = info of one edge of graph 
</p>
<p>3. Unlimited local computation at each node
</p>
<p>4. Nodes have local information about graph
</p>
<p>• Goal: Answer a question about the graph
</p>
<p>  
</p>
<p>• Quantum Model: Qubit Communication
</p>

</p>
<p>and the (weights of) edges it is incident upon
</p>

<div class="page"><p></p>
<p>Make use of Distributed Grover Search for finding Triangles!

<p>Idea: 
</p>
<p>• Triangles live in 𝑉 × 𝑉 × 𝑉, so partition that space 
</p>
<p>• Have each node search an assigned partition for triangles 
</p>
<p>• Do this via sets 𝑽𝟏 × 𝑽𝟐 × 𝑽𝟑, where 𝑽𝟏 = 𝑽𝟐 = 𝑛1/4, 𝑽𝟑 = n1/2, 
</p>
<p>and they each 𝒘 ∈ 𝑉1 or 𝑉2 contains 𝑛3/4 nodes, and each 𝒘 ∈ 𝑽𝟑 contains 𝑛1/2 
</p>
<p>nodes.
</p>
<p>• So 𝑽𝟏 × 𝑽𝟐 × 𝑽𝟑 has 𝑛 elements that are each sets of nodes → each node gets one

<p>• Making use of fast routing, the bottleneck becomes searching through the elements
