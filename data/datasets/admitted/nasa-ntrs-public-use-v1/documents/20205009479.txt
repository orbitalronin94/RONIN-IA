Motivation & Project 
Summary

• Motivation/Problem 
Statement:
– Actuation performance testing 

is a critical step which 
determines if a NGMSA 
functions correctly as 
expected. 

– The existing test system is not 
able to handle the large format 
NGMSAs currently under 
development.

• Project Summary:
– This project will build a 

characterization system that 
can test operability of large 
format microshutter arrays, 
which cannot be done with the 
existing test system that has 
been used for 64 x128 format 
array because of extremely 
limited capability in terms of 
size and function.

Project ObjectivesProject Objectives

• What were your goals to accomplish?
• An actuation test system large enough to handle an MSA 

with size of 90mm x 90mm.
• Automated probing, actuation & image acquisition by 

motorized translation stages.
• Process acquired images to data that represent each 

shutter’s operability status.
• Were they accomplished?

• The test system platform with a motorized sample stage 
manipulation system and machine vision system were 
completed. An operating system program was developed 
in LabVIEW to automatically acquire mosaic images in 
high-definition.

• The image processing code originally developed for the 
JWST microshutter array test system is being 
implemented in this system.

Process/Materials/
Methodology
Process/Materials/
Methodology

• How did you accomplish the objectives?
• By designing the system, procuring and 

assembling COTS parts, designing & machining 
custom parts, then writing custom software to 
operate the system.
• Three motorized stages are employed to 

independently manipulate the MSA, imaging 
optics and probe assembly.

• A probe card with multiple contacts (25) is used 
instead of individual probes. This change 
effectively reduces the amount of time required 
for testing each array.

• The test procedure is automated by LabVIEW 
operation software.

Results & ConclusionsResults & Conclusions

• Results:
– An automated large 

format MSA actuation 
test platform was 
completed.

– Automated mosaic 
image acquisition was 
successfully 
demonstrated.

– The driver electronics 
piggyback PCB is 
currently being 
populated.

• Conclusions:
– This test system enables 

actuation performance 
testing of large format 
MSAs, which was 
impossible with the 
previous test system.

– This system is scalable, 
which means it can 
expedite test procedures 
of smaller arrays as well.

Challenges Encountered / 
Lessons Learned
Challenges Encountered / 
Lessons Learned

• Describe challenges, if any, and how they were 
overcome/handled, and/or lessons learned, if 
applicable
• Large format MSA fabrication processing was 

stopped, as well as the driver electronics 
fabrication due to the COVID-19 pandemic. As a 
result, we were not able to demonstrate actual 
array actuation testing.

• We determined that the current imaging optics 
does not provide a wide enough field of view, 
which necessitated a large number of sectional 
image acquisitions. Alternative optics are under 
test to overcome this limitation while still 
maintaining adequate resolution (camera pixel 
elements per shutter).

– Finish the piggyback driver PCB and actuate a large format MSA.

• What potential customers or follow-on funding sources are 
there for this technology?
– The customer is the GSFC NGMSA development team.
– Funding to finish and operate the system will be provided by the current 

NGMSA SAT program 
• How should GSFC’s investment in your technology be 

leveraged to further improve our competitive posture in this 
area?
– Potential applications for the large format NGMSA are in CETUS, LUVOIR 

and HABEX multi-object spectrometer instruments.  This test system will 
help speed our internal development of the NGMSAs to ready them in time 
for those mission applications.
