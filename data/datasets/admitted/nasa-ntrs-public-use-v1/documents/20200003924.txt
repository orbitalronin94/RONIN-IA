Onto Mappings using Accelerated Neural Networks
in collaboration with GSFC
Problem: It has been theoretically proven that a neural network can be
used to represent any function. There are no benchmark tests
demonstrating whether neural networks representing a function
algorithmically or computationally perform better.
Objective: Demonstrate the basis functions in which a neural network
representing each function, implemented on a GPU, can outperform
the function itself when running on a CPU

Operational And Performance Capability
Should it be found that the neural network representations can
outperform the as-written code implementations, these
findings enable:
• A library of neural networks that are characterized in their
performance for replacing familiar code subroutines
• Reusable set of benchmark subroutines for future HPC
testing
• Risk reduction for a larger HPC effort that adopts submitted
code to an HPC GPGPU environment by scanning the code
and replacing it with trained GPGPU neural network
predictor implementations

Technical Approach
• Identify a small set of benchmark subroutines and craft neural
networks that emulate each subroutine
• Compute algorithmic performance of benchmark subroutines
and compare to algorithmic performance of neural network
prediction – include sine wave extrapolation and FFT in this
set
• Compare the computational performance of each set of
benchmark subroutines against the computational
performance of their neural network representations
•
Measure neural network performance on both multicore CPU and GPUs
• Compare computational performance of weaving neural
network prediction calls on GPUs against normal subroutine
calls

Analysis of Thermocouple Interference
in collaboration with NESC
Purpose: Characterize the influence Earth’s magnetic field has on
Shuttle/Orbiter sensor readings during Entry, Descent, and Landing.
Problem: Correlations between flux
of Earth’s magnetic field and
thermocouple readings were unable
to be verified using rudimentary
time series analyses measurements.

Objective: Develop an
algorithmic approach for
comparing and interpreting the
relationship between the
dynamics presented by
thermocouple readings with the
dynamics of Earth’s magnetic
field.

Operational And Performance Capability
• Mathematical characterization of the relationship between
Earth’s magnetic field behavior and shuttle mission readings
• Ability to computationally analyze recurrences in the phase
space of a dynamical system
• Data-agnostic R implementation that can be open-sourced or
published as a software library

Technical Approach

Current Status

• Convert time series data from both the magnetic field and
shuttle missions into recurrence networks, in which properties
of their phase space can be computationally measured,
clustered, and compared
• Identify key measurements that indicate changes in the phase
space for Earth’s magnetic field and thermocouple readings
• Transform each mission dataset into a recurrence network and
perform clustering (unsupervised learning) of recurrence
network features to group similar missions
• Compare spectral and recurrence network properties of the
magnetic field measurements to equivalent properties of
thermocouple data during those missions

• Used recurrence network data curation technique to compare
Shuttle/Orbiter sensor readings and magnetic field activity
• Submitted an abstract for presentation of data analysis results
to DATAWorks 2019
• Comparing ground track data to clusters of similar missions to
demonstrate that recurrence properties are related to mission
maneuvers
• Convert magnetic field magnitude data using Faraday’s Law to
model the effect of Earth’s magnetic field on a conductor on
orbiter missions and measure these recurrence properties

• Convolutional Neural Network (CNN)
