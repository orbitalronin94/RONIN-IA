Decision Tree Theory
This model was developed to provide a faster segmentation model suitable for
real-time feedback applications. It uses the HSV (hue, saturation, value) and
Laplacian filter parameter space instead of RGB since the separation between
target classes (sample, shock, background) is larger.



Minimum number of samples required to split an internal node = 500
Depth of the tree = 10
Input params: HSV and laplacian HSV of single pixel 
Output: Sample, Shock, Background classification
