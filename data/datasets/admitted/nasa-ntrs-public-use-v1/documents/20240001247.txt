Motivation
Heart rate data is often used in lab 
studies to gain insight into various 
physical and psychological health, sleep, 
and team science outcomes (e.g., 
autonomic arousal as indicated by the 
ratio of high and low frequency, an 
indicator of stress). Using it longitudinally 
in spaceflight could allow crews to 
monitor themselves more autonomously 
but, like other biological signals, using 
heart rate data poses challenges. 
Managing and using this big data source 
has been neglected due to its complexity 
and has resulted in stagnated heart rate 
related science and missed opportunities 
to optimize its usage. The purpose of this 
project is to develop and validate a data 
processing pipeline that reads, 
preprocesses, analyzes and tidies ECG 
data collected in spaceflight analog 
studies.



Method
1. Conduct literature review (n = 167)
2. Summarize and try common 



processing pipelines
3. Try to develop a pipeline using 



existing libraries
4. Make a new library to address 



identied gaps
5. Preliminary validation



Workflow: Read in data > Filter, clean and interpolate > Metric generation and visualization
Features: Automatable + Batch apply + File-type agnostic + No black box + Flexible

Common Pipeline Structure
• Read in signal & segment (if 



needed)
• Remove noise (outliers, 



artifacts, baseline drift)
• Extract R-R intervals
• Generate heart beats
• Interpolate missing or 



removed beats (if needed)
• Generate metrics of interest



Summary: 
Kubios is a frequently used research tool 
but has a heavy manual processing 
requirement. There are difficulties 
handling Big Data and the output is not 
easily parsed. The MatLab packages are 
more cardiology-centric, some difficult to 
use, and do not always provide the 
behavioral health related metrics. 
HeartPy and rHRV would be ideal but 
both are missing what the others provide. 



HeaRRt: New R package for Heart Rate Research
A comprehensive R package with capabilities from HeartPy & compatibility with rHRV

Conclusion
HeaRRt is a package capable of 
providing the essential steps in a 
heart rate processing pipeline for 
research. Preliminary results show 
little to small differences in the data 
comparison, a more conservative beat 
removal algorithm, and better speed. 
Results are comparable to gold 
standard research tools. With 
continued refining, the HeaRRt + 
rHRV pipeline can be a useful, valid 
and robust alternative to the current 
tools. Future work includes adding 
additional features (filters, logging for 
reproducibility, etc.), and further 
validation.
