NDAS 


NASA’s Data Acquisition Suite (NDAS) is a data collection and analysis software suite designed to support rocket propulsion testing.


Project Goals 


Provide a NASA-owned and maintained software platform. 


Provide a modular and customizable software suite that supports multiple hardware platforms.


Provide a common user experience to drive consistency across test complexes and centers.





Project History


2011 : NDAS Project began as an RPT-level effort


2014 : Deployment to SSC A2 for J2X


2015 : Deployment to SSC A1 for RS-25 


2016 : Deployment to SSC B2 for SLS Green Run


2017 : Deployment to SSC E2 for EUS


2018 : Deployment to WSTF Test Labs


2019 : Deployment to MSFC East 115 & 116


2020 : Deployment to SSC E1 and E3


2021 : Deployment to MSFC 400 Area & SSC HPGF


2022 : Deployment to MSFC 40k Area


2023 : Established Core Team


Software Engineering Team 


Combined Civil Servant & Contractor Team 





Expertise in software engineering, data acquisition instrumentation, embedded systems, electrical systems, and controls engineering.





Hold multiple NI LabVIEW certifications including Developer, Embedded Developer, Architect, and Champion.





Software Capabilities 


Data acquisition, scaling, visualization, and recording of sensor data. 


Software acquisition rates up to 400k sps provide flexibility for multiple project requirements.


Capable of communicating and display/recording external systems data.


Post processing into multiple file formats


Software Lifecycle Process


DevOps (Development and Operations) aims to integrate the work of development teams and operations teams by facilitating a culture of collaboration and shared responsibility.





Agile Scrum is an agile project management framework that helps teams structure and manage their work through a set of values, principles, and practices.


NDAS Core Platform


Core software platform allows for software solutions within the NDAS ecosystem


Thrust Vector Control System (TVCS) and Liquid Level Gauge (LLG) utilize streaming, display, and recording capabilities from core platform


Potential to provide other solutions

Suggested System Requirements


Operating System


Windows 10 fully supported including LTSC


Windows 11 is being tested


Windows 7 can be supported but not recommended.





Processor 


Intel® Core™ i3 Processor, Intel® Xeon ® E5 comparable or better





RAM


8Gb DDR4 or more





Internal Storage 


~512GB average. 


Actual usually determined by use cases (ie Logging v. Display)





Network


1Gbe port or better





Software Dependencies: LabVIEW runtime, .NET, MySQL, various NI libraries for acquisition and calibration hardware





In-Field Examples: HP Z440, HP Z420, HP Z2 G9 Mini, HP Z6
