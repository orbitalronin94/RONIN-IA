External CAMMP Overview
eCAMMP Analyses - ISS Configuration



▪ SSP 30219 (Space Station Reference Coordinate Systems)



• Establishes a set of coordinate systems to be used when reporting data between the International Space Station (ISS) Program Participants



▪ SSP 50949 (ISS Configuration Document)



• Details the ISS baseline configuration (external platforms, element configuration, camera port plan, ISS port connectivity, VV support 



hardware, robotic elements, retroreflector locations, and internal topologies)



▪ ISS Reference Information



• SharePoint site providing ISS overview data such as Russian Configuration Numbers, Camera Port Configuration, Current ISS Configuration 



Images, External Carriers and Payload Site configuration (contained within ISS Reference Packet)



o External Carrier Site configuration data feeds into IDRD Appendix E



o Updated on an ongoing basis as planned on-orbit operations are confirmed

MAGIK Overview
ISS Robotics General Information



▪ OM7/ISS Robotics Integration leads the coordination with various 



stakeholders to ensure robotic readiness in support of ISS objectives



▪ Works closely with FOD through the life cycle to prepare for 



Payload Operations



▪ MSS (Mobile Servicing System) and JEM RMS (Japanese Exploration 



Module Remote Manipulator System) are the primary methods for 



installation, operation, and disposal of external payloads on the 



International Space Station



• JEM RMS, operated by JAXA, is composed of Main Arm and Small 



Fine Arm (SFA)



• Used to install and service payloads on the JEM External Facility 



and JEM Airlock



▪ Canadian Space Agency (CSA) developed and jointly operated with 



NASA, MSS is made up of:



• SSRMS (Space Station Remote Manipulator System)



• SPDM (Special Purpose Dexterous Manipulator)



• Mobile Base System (MBS) installed on the Mobile Transporter 



(MT)



SSRMS



SPDM

▪ iCAMMP/IVCWG Definitions



• Maintains 3D CAD models of the interior configuration of ISS



• Performs analyses on the planned and current configuration



• Internal Volume & Configuration Working Group (IVCWG) is the ISS 



community working group that meets monthly to discuss internal



configuration changes and requirements



▪ Types of analyses performed by iCAMMP include:



• I-4.5 mo. and I-1.5 mo. Increment Configuration Analysis



• Placement Analysis for systems hardware



• Cargo Translation Analysis



• Stowage Capability Analysis



▪ Additional iCAMMP Responsibilities



• Document and maintain SSP 50261-01 GGR&C Section 13 



• Document and maintain USOS Rack Topology (baselined in IDRD)



• Integration activities for internal volume configuration

| HUMAN SPACE FLIGHT TECHNICAL INTEGRATION CONTRACT (HSFTIC)| 17



▪ Placement Analyses



• Performed as requested to identify locations for systems hardware 



installation or relocation



• Requestor provides requirements/constraints and multiple locations are 



assessed for GGR&C Section 13 requirements



▪ Increment Analyses



• Performed at Increment minus 4.5 months (I-4.5m) and at I-1.5m



• Verifies compliance of planned internal configuration of the US Lab, US 



Airlock, PMAs, and Nodes 1, 2, and 3 to GGR&C Section 13



• Multiple organizations' data and previously completed analyses are used



to build the Increment configuration models



▪ Stowage Analyses



• Performed to analyze stowage configurations supplementing hardware



placement or protrusion assessments



• Assessments can include:



o Analyzing volumetric capability



o Packing efficiency studies



o Images for stowage visualization
