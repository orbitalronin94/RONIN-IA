2 - Introduction
Hardware-in-the-loop simulation: Objectives



Hybrid simulation of a generic robotic space intervention system in 1-g environment with:



Actual hardware for manipulation task with a suitable industrial robot
A real-time dynamic simulator for simulating the space manipulator kinematics and dynamics,
in its own space environment (on-orbit, zero-g, etc.)



Possibility of choosing which capabilities of the space robotic system are to be simulated or
replicated in hardware



Reduce cost of on-Earth test/validation/verification of a space robotic systems by pushing to
real-time dynamic simulations the aspects difficult to replicate on Earth (e.g. simulating the
effect of thrust on a long flexible manipulator)



Perform a parameterized performance study of a space robotic mission



Discover the benefits, limitations and sensitivities of the robotic system to known performance
contributors such as properties of the robot controller and sensors



Verify the performance sensitivity to key hardware and software characteristics.



Earlier steps: Use Monte Carlo simulation methods to predict robot arm performance against
selected hardware and software characteristics



Later steps: validate these Monte Carlo predictions on robot hardware

4 - Real-Time Dynamic Simulator
Real-time simulation of flexibility



Flexibility with augmented model (+ 1 DoF per joint)



Elasticity is reduced at the joint level, along the torque trans-
mission path between the motor and the joint



Dynamic model is augmented by adding extra branches



This is equivalent to attaching each motor to the original joint
through a spring/mass/damper
Total degrees of freedom doubles



The ”spring” acts only on the axis of the motor; every other
part of the structure is supposed rigid



This model assumes the dominant action is the elasticity of the
torque transmission between the motor and the joint



This model requires only 50µs to perform one update step on
a 7-DoF robot

5 - Contact Forces Extractor
Dynamic Parameters Estimation



The Force/Torque sensor simulator needs to know the dynamic parameters of its load.



Dynamic Parameters Estimator objectives:



Identifies dynamic parameters of a robot end-effector



Estimates velocities and accelerations of the end effector center of mass using an Extended
Kalman Filter (EKF)



Estimates the externally applied forces and moments acting on the end effector using the
EKF



Primary use: contact forces isolation in a 1-G environment for the HIL simulator



How it works:



Inputs: 12-DoF sensor data (linear/angular accelerations, forces and moments)



Inputs: end effector pose w.r.t the robot base, which is provided by the robot controller



A mathematical model of the end effector dynamics developed using Maple CAS provides
a solution for the F/T sensor inertial forces



Simulated inertial forces are subtracted from the F/T readings to isolate the contact forces

8 - Conclusions



Investigated feasibility of an hybrid hardware-in-the-loop simulation environment of a generic
robotic space intervention system in 1-g environment with:



Actual hardware for manipulation task with a suitable industrial robot
A real-time dynamic simulator for simulating the space manipulator kinematics and dynamics,
in its own space environment (on-orbit, zero-g, etc.)



Major challenge: implementation of real-time dynamics



Approach seems promising; this solution allowed us assess several possible problems such as
tele-manipulation in zero-g in case of large and flexible manipulators



Cost of the simulation environment was greatly reduced with respect the adoption of large
mechanical platforms



The optimized implementation is suitable for advanced statistical analysis such as a parameter
sensitivity analysis that requires a very large number of simulation runs
