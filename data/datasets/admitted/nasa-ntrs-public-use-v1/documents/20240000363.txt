</p>

<div class="page"><p></p>
<p>National Aeronautics and Space Administration 4
</p>
<p>• NASA Vision 2040 envisions a cyber-physical-social ecosystem of experimentally validated 
computational models, tools, and techniques, along with the associated digital tapestry, that 
can enable rapid, optimized, ‘fit-for-purpose’ design of materials, components, and systems
• Unrealistic to assume one tool will be used by an organization for all data analysis and storage
• Effective information management tools should be able to interact with other, specialized tool and 
</p>
<p>databases – overcome both technical and cultural challenges with digital transformation
</p>
<p>• Present two different methods for capturing, analyzing, and storing test data within a robust 
information management system:
</p>
<p>1. User developed analysis tool that directly reads raw data, analyzes it, and stores it in the
database
</p>
<p>2. A database tool that interacts with both an existing analysis software and database to
capture and link additional information outside of the initial tool’s scope 
</p>
<p>Developing a Cyber-Ecosystem of Validated Tools and Models is 
Paramount for ICME </p>
<p></p>
</div>
<div class="page"><p></p>
<p>National Aeronautics and Space Administration 5
</p>
<p>• Goal: Develop an automatic framework to capture, analyze, and store bulk experimental 
test data in the NASA GRC ICME Schema
</p>
<p>• Benefits
1. Reduce User Effort for 
</p>
<p>Data Management
</p>
<p>2. Provide traceability between 
test machine calibration and 
test performance
</p>
<p>3. Consistency in data analysis
and reduction
</p>
<p>PyMILab: Efficient Data Analysis and Importing is Critical to 
Effective Data Management
</p>
<p>Automatic Placement + Data Analysis → Higher 
likelihood of organizational adoption</p>
<p></p>
</div>
<div class="page"><p></p>
<p>National Aeronautics and Space Administration 6
</p>
<p>• Test data is categorized as either Standard or Generic
</p>
<p>• Standard – Tensile, Relaxation, Creep
</p>
<p>• Generic – Combination of various standard test stages
</p>
<p>• For each Standard Test, data analysis of raw data 
performed 
</p>
<p>• Tensile – Modulus, Yield
</p>
<p>• Creep – Creep Zones, Creep Stress
</p>
<p>• Relaxation – Relaxation Stress, Loading/Unloading 
behavior
</p>
<p>• Specific subroutines written for each test to perform the 
data analysis/parameter extraction
• Store how parameters were calculated and write to each record 
</p>
<p>to maintain material/test pedigree
</p>
<p>Experimental Data Automatic Import Tool:
Data Analysis for Standard Tests</p>
<p></p>
</div>
<div class="page"><p></p>
<p>National Aeronautics and Space Administration 7
</p>
<p>• Generic Tests contain various stages of one of the 
standard test types
</p>
<p>• Stages endpoints are automatically recognized by 
implementing a knee-point algorithm
</p>
<p>• Control Modes are determined from analyzing the 
stress-time and strain-time behavior of each stage
</p>
<p>• Stage Type is determined using the table below
</p>
<p>Experimental Data Automatic Import Tool:
Defining Generic Tests</p>
<p></p>
</div>

<p>National Aeronautics and Space Administration 8
</p>
<p>Automatic Linking Capability Enables Pedigree Maintenance
• From the information defined in the Excel Test Matrix supplied by the user, links to other 
</p>
<p>records in the database are automatically populated
• Automatic links to the test equipment and measurement devices ensure that how the data was captured 
</p>
<p>is maintained in the database
</p>
<p>• If a test is out of spec. or the machine is found to be out of calibration, automatic linking can provide a 
list of potentially effected records to ensure that the data in the database is correct</p>
<p></p>

<p>National Aeronautics and Space Administration 9
</p>
<p>Shape Memory Materials Database
• Shape Memory Alloy (SMA) Materials require additional testing, analysis, and 
</p>
<p>attributes/data collection to properly characterize the material for model development
</p>
<p>• The shape memory alloy team at NASA GRC has developed the Shape Memory 
Materials Database (SMMD) to capture literature and in-house test data on shape 
memory materials
https://shapememory.grc.nasa.gov/
</p>
<p>• Offers users an interactive and 
intuitive way to compare different 
SMA materials for use in various 
applications from vetted, published
data sources
</p>
<p>• Purpose: Offer public a single, free
location to view and compare literature
and government SMM Data</p>

<div class="page"><p></p>
<p>National Aeronautics and Space Administration 10
</p>
<p>SMAnalytics Tool
• For in-house test data, the SMAnalytics Tool has also been developed
</p>
<p>• Performs data analysis for SMA Materials for:
• Uniaxial Constant Force Thermal Cycling (UCFTC)
</p>
<p>• Uniaxial Pre-Strain and Thermal Free Recovery (UPFR)
</p>
<p>• Differential Scanning Calorimetry (DSC)
</p>
<p>• Can be downloaded here: https://software.nasa.gov/software/LEW-20278-1
</p>
<p>• Allows analysis of variants of these methods, such as multi-cycle, multi-stress UCFTC and UPFR. 
</p>
<p>• Provides automatic extraction of multiple properties including transformation temperatures, 
transformation and residual strains, strain recovery, and other related properties.
</p>
<p>Example output from DSC Analysis using SMA\Analytics</p>
<p></p>
<div class="annotation"><a href="https://software.nasa.gov/software/LEW-20278-1">https://software.nasa.gov/software/LEW-20278-1</a></div>

<p>Connecting SMAnalytics and SMMD with Granta MI
• Currently, analyzed data can be sent from the SMAnalytics Tool to the SMM Database
</p>
<p>• Only point-wise values are sent to the database → no information is captured on the raw data curves, 
test pedigree, material pedigree, etc. that must be captured to maintain the digital thread
</p>
<p>• Current Work: Connect SMAnalytics Tool with Granta MI to capture the raw data, data 
curves (e.g., hysteresis curves) and necessary information not captured by to the SMMD
</p>

<p>National Aeronautics and Space Administration 17

<p>Automatic Placement of Data into Granta MI
• Records are automatically written to the Test Data: Thermomechanical Table in Granta MI 
</p>
<p>from the SMAnalytics Data Importer
• A SMA subset was created to store additional attributes
</p>
<p>unique to SMA Materials (e.g., Transformation 
Temperatures, Peak Heat, etc. for Austenite and 
Martensite Phases)
</p>
<p>• Subsets are used in Granta MI to group records 
in a Table with common properties together, 
making it easier for MI users to work with smaller, 
targeted collections of data of interest for a specific 
purpose
</p>
<p>• Records are organized in the database by:
</p>
<p>• Alloy Base
</p>
<p>• Alloy
</p>
<p>• Test Type
</p>
<p>• Individual Specimen</p>

<p>• Data Informatics and Effective Data Management are critical to enabling 
ICME and achieving the NASA Vision 2040
• Ensure the integrity of our data, prevent loss of institutional knowledge, and trust 
</p>
<p>that our data is protected
</p>
<p>• Unrealistic to assume one tool/database will be used to capture all 
material information
• Information Management systems must be able to communicate with specialized 
</p>
<p>databases to establish a “digital ecosystem” for materials information
</p>
<p>• At NASA GRC, the recently developed Shape Memory Material Database 
and SMAnalytics Tools are being connected with the NASA GRC ICME 
Schema to provide traceability between test data, analysis, and design 
data for shape memory alloys
</p>
