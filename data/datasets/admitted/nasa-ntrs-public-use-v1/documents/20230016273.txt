<p>Data Split
</p>
<p>8Predicting the Appearance of Sunspots on the Solar Surface Using Machine Learning
</p>
<p>Training:
• Active Regions: 58 Active Regions (November 2010 to December 2022)
• Physical Parameters: 4 Frequency Range Acoustic Power Maps
• Map Split: 63 Tiles Each Power Map (Omitting Top and Bottom Rows)
• Sliding Windows: 140 Different Intervals
• Points in Each Window: 80 Points (1 hour cadence)
• Total Parameters: 58x4x63x140x80 = 164 Million Data Points
Testing:
• Active Regions: 3 Active Regions (December 2022 to April 2023)

<p>Challenges Addressed Using HECC Systems
</p>
<p>11Predicting the Appearance of Sunspots on the Solar Surface Using Machine Learning
</p>
<p>• Data Transfer
• The HMI instrument takes 2TB of data per day/ 10 PB raw data since SDO launch in 2010. 
• The data for every AR analyzed in this project takes up 150GB of space.
• A total of 9.15 TB worth of data (150GB x 61ARs) was transferred from Stanford/JSOC and save on Lou 
</p>
<p>Front End (lfe) using the NASA Secure Unattended Proxy (sup shiftc command). 
• Data Preprocessing
</p>
<p>• The 9.15TB AR data was processed on Pleiades Front End (pfe) and was reduced down to 350GB creating 
our ML ready datasets.
</p>
<p>• Such a process could not be carried out on a personal computer due to storage and computational limits.
• Machine Learning (full scale ML model run time):
</p>
<p>• Personal Computer: Apple M1 Pro CPU (up to 10 cores) would take &gt;2 Weeks.
• Aitken CPU node: Intel Xeon Gold 6248 (40 cores) takes 9 Days.
• Sky Electra GPU node: NVIDIA Volta V100 take 30 Hours (x7.1 Speed-Up).
• Further optimization by utilizing all GPUs in a node (4 or 8 in total) is possible. Code needs to be optimized 
</p>
<p>for parallel processing. For a shallow network like ours might not be worth it.</p>
<p></p>

<p>Conclusions
</p>
<p>12Predicting the Appearance of Sunspots on the Solar Surface Using Machine Learning
</p>
<p>• We create a machine learning ready dataset of emerging solar active regions aiming to:
• Understand the physical processes on the surface of the sun
• Predict emergence of active regions: A drop in intensity can be predicted in a tile 18 hours 
</p>
<p>in advance without false positives.  
• Calculated acoustic power maps carry precursor information associated with the decrease in 
</p>
<p>continuum intensity on the solar surface
• Machine learning models (LSTM/Transformers) can capture this information creating early 
</p>
<p>warning systems for the emergence of solar active regions
