# Quarantined datasets

Nothing in this directory may be used for training. Reasons include unknown or incompatible rights, account/API-key requirements, gated terms, missing source revisions, unclear document provenance, unresolved OCR/edition rights, holdout contamination, or failed quality/integrity checks.

A quarantine record must state:
- source and exact revision (if known);
- reason for exclusion;
- checks already performed;
- evidence required to reconsider;
- explicit `training_eligible: false`.

Never silently move quarantined records into candidates or admitted data. Reconsideration requires a new audit record.
