<p>Context
• Developed on NASA Goddard Internal Research funding (IRAD)
</p>
<p>• Goal: create and infuse a broadly applicable process to rapidly develop 
lightweight spaceflight structures
</p>
<p>• Method: build and test parts for diverse NASA applications
</p>
<p>• Status: development of typical metallic structures now automated
• Requirements➡parts for fab in 1-2 days(!)
</p>
<p>• Demonstrated by test 
</p>
<p>• Being applied to NASA missions
</p>
<p>• Goals of this presentation
• Share lessons learned about practical implementation of Generative AI 
</p>
<p>• Enable products to improve the mass/stiffness/strength of structures by 2x-4x 
while reducing development time/cost by ~10x
</p>
<p>• Engage the Generative AI community
</p>
<p>"Not every change is an improvement, but every improvement is a change" 2</p>
<p></p>

<p>Evolved Structures: Prompt Engineering for Structures 
(1) Create a prompt to digitally encode structure requirements into software 
</p>
<p>• Follow written Evolved Structures Guide for NASA applications 
</p>
<p>(2) Use Generative Design Al to evolve optimal designs meeting requirements 
• Using COTS software adapted for GSFC needs 
</p>
<p>(3) Fabricate parts directly from Generative Design output using Digital 
Manufacturing (software+ robots) 
• Using industrial processes such as automated CNC and Additive Manufacturing (AM) 
</p>
