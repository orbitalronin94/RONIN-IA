Machine learning is critical to ICME
Need for effective and efficient storage of data and models with full traceability
NASA GRC ICME schema separates data and models into two different tables
Reference Data: ML stores virtual data created to train ML models
Models: ML stores actual models
Each example in a training set is stored in its own individual record
Necessary to follow database best practices within Granta MI
Identified feature requests that can enable machine learning data/models to be efficiently and effectively stored in the Granta MI platform
