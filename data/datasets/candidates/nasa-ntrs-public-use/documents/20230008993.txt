<p>Overview</p>
<p></p>
<p>The core idea behind using machine learning (ML) for defect detection is that it can be used to detect flaws as they are being formed in an AM part. As the part is being made, a near-infrared (NIR) sensor records each layer and creates an image of the entire build layer. These images, usually thousands, can be compiled into a ‘3D’ array of the entire part. ML tools, such as a convolutional autoencoder (CAE) can go through these images and highlight potential anomalous regions of your part.</p>
<p></p>
<p></p>
<p></p>
<p></p>
<p></p>
<p>	</p>

<p></p>
<p></p>
<p>A CAE is an unsupervised machine learning neural network with encoding and decoding layers. </p>
<p></p>
<p>These are used in convolutional layers which can be trained to ‘learn’ what features correspond to an initial, nominal input.</p>
<p></p>
<p>The Encoder abstracts these input images down and identifies key features. </p>
<p></p>
<p>The Decoder uses these features from the defect regions, in conjunction with the initial training regimen, to reconstruct a new, nominal part image.</p>

<p>What is a Convolutional Autoencoder?</p>
<p>The new nominal copy is compared to the defective image, and the absolute difference between the two is found. </p>
<p>This ‘error difference’ dataset is then filtered using a 3-sigma threshold to mark locations whose reconstruction error is greater than 3 standard deviations from the mean of the layer; which ostensibly should be the faults in question. </p>
<p>		</p>
<p>An initial nominal version of the desired part is created by first removing noise and outlier pixels on the input slices that fall outside of a desired histogram range, before filling them in again with a Navier-Stokes inpainting algorithm.</p>
<p>This preprocessed version of the original part image is used as input to train the CAE and create a nominal, abstract version, of the original defective image.</p>
