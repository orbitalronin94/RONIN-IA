<div class="page"><p></p>
<p>Executive Summary
</p>
<p>– LS-DYNA Explicit Finite Element Analysis software and CADPROG Internal Ballistic Analysis 
</p>
<p>code are integrated as a single modeling tool to analyze pyro-mechanical devices. 
</p>
<p>– Coupling these two codes allows the ballistic calculations to be performed without modeling the 
</p>
<p>propellant in an FEA mesh. At each LS-DYNA time step, CADPROG is run analytically using 
</p>
<p>the kinematic data (stroke, velocity, chamber volume) fed back from the LS-DYNA simulation. 
</p>
<p>The calculated pressure is then applied to a piston or any applicable surface mesh in LS-DYNA 
</p>
<p>model interactively.
</p>
<p>– All external loads such as friction, damping loads, assisting/resisting loads, locking/unlocking 
</p>
<p>loads are modeled in LS-DYNA and coupled with pressure loads from CADPROG to create a 
</p>
<p>fully defined equation of motion 
</p>
<p>– Both codes are written in Fortran 77. CADPROG is integrated in the LS-DYNA source code as 
</p>
<p>a user-defined subroutine and recompiled to generate a custom executable.   
</p>
<p>Disribution A : Approved for Public Release, Distribution Unlimited. 2</p>
<p></p>
</div>
<div class="page"><p></p>
<p>LS-DYNA Overview
</p>
<p>• Developed by Livermore Software Technology Corp (LSTC), LS-DYNA is a physics-based 
</p>
<p>explicit FEA code that uses time integration to solve short duration transient and highly nonlinear 
</p>
<p>dynamic problems
</p>
<p>– Extensive material model and Equation-of-State library, highly accurate contact algorithm and ability for 
</p>
<p>Fluid-Structure Interaction (FSI) make LS-DYNA an excellent tool for evaluating complex mechanical 
</p>
<p>and structural systems.  
</p>
<p>• Widely used for detonation problems using built-in JWL equation of state.
</p>
<p>• While modeling the deflagration of a solid propellant with LS-DYNA is possible, it is very limited 
</p>
<p>and mostly applicable to airbag systems that use gaseous nitrogen generated by burning of 
</p>
<p>sodium azide. 
</p>
<p>• Allows users to define their own custom material models, equations of state and loading models 
</p>
<p>through user-defined subroutines.
</p>
<p>Disribution A : Approved for Public Release, Distribution Unlimited. 3</p>
<p></p>
</div>
<div class="page"><p></p>
<p>CADPROG Overview
</p>
<p>• CADPROG is a one-dimensional internal ballistic code developed by NSWC Indian Head 
</p>
<p>Division and is widely used to analyze CAD/PAD devices and ejection seat catapults
</p>
<p>– Differential Equations of State and Energy are solved using 4th Order Runge-Kutta Method 
</p>
<p>• Capable of modeling solid propellants with many geometries, such as multi-perforated cylindrical 
</p>
<p>grains, spherical ball powders, flakes, slabs. 
</p>
<p>• Single and Hi-Lo dual chamber CAD/PAD devices can be modeled with a mixture of up to three 
</p>
<p>propellant types.  
</p>
<p>• NASA/JSC made various updates to the source code over the years to improve its capabilities: s
</p>
<p>– Improved heat-loss module for during and post-burnout heat loss
</p>
<p>– Added stroke-dependent external load capability
</p>
<p>Disribution A : Approved for Public Release, Distribution Unlimited. 4</p>

<p>Creating LS-DYNA User-Defined Executable
</p>
<p>• Fortran source code that contains a collection of subroutines is required to 
</p>
<p>create a custom LS-DYNA executable.
</p>
<p>– The Fortran file dyn21.f can be obtained from LSTC.
</p>
<p>– dyn21.f is modified by the user to integrate the user-defined loading, in this case the entire 
</p>
<p>CADPROG code.
</p>
<p>– dyn21.f must be compiled by using the latest version of Intel® Visual Fortran Compiler.
</p>
<p>• Running the makefile supplied by LSTC compiles the file and links with the object files that are also 
</p>
<p>provided. 
</p>
<p>• The new LSDYNA.EXE file should be selected as the solver when running LS-DYNA.     
</p>
<p>– Subroutine receives TIME, TIMESTEP, elemental X and V input and initial conditions from 
</p>
<p>the LS-DYNA run,  and outputs calculated pressure curve, udL(i), interactively for each 
</p>
<p>element “i” on selected pressure surface.    
</p>
<p>Disribution A : Approved for Public Release, Distribution Unlimited. 6</p>

<p>Simplified Pyro Thruster Example
</p>
<p>• Flexible Housing and Rigid Piston
</p>
<p>• Piston pushes a 190 lbs mass 
</p>
<p>• FEA Model contains 26,256 solid elements
</p>
<p>• Housing constrained at one end
</p>
<p>• 10 inches of stroke
</p>
<p>• Propellant: 7-perforated HES5808 grains
</p>
<p>• Igniter: BKNO3
</p>
<p>• Contact with static and dynamic friction coeff.
*CONTACT_SURFACE_TO_SURFACE
</p>
<p>• Various external assisting and resisting loads 
</p>
<p>applied to piston end as nodal force. 
</p>

<p>Future Work
</p>
<p>• In our current model, pressure is applied only on pre-selected mesh surfaces 
</p>
<p>such as the piston area and initial volume walls. 
</p>
<p>• Adding capability to update pressure application mesh surface (inner walls of 
</p>
<p>gas chamber) as the volume expands will allow full structural analysis (stress, 
</p>
<p>strain) in real time.
</p>
<p>– Euler mesh inside chamber volume with user-defined CADPROG EOS could be an option 
</p>
<p>• Hi-Lo chamber ballistic capability can be added to model the gas flow from high-
</p>
<p>pressure chamber to low-pressure chamber by using unique LS-DYNA solvers 
</p>
<p>such as ICFD for incompressible and CESE for compressible flows.
</p>
<p>Disribution A : Approved for Public Release, Distribution Unlimited. 13</p>
