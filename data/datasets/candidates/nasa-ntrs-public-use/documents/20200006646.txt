atmospheric constituents, and surface
properties consistently in time and space to

POWER – Modernization
Old POWER (SSE v6):
○ Over 200 parameters
○ HTML and ASCII tables only formats only
○ Data backend production was not scalable; required a
complete rewrite to reprocess a parameter
○ Original graphics not supportable due to unsupported
software and security issues
New POWER (v1.0.9):
○ Over 200 parameters; from latest NASA science version such
as SRB, CERES and MERRA-2
○ ASCII, CSV, geoJSON, NetCDF4, ICASA, GeoTiff formats
available with user Community based unit conversions
○ Increased spatial/temporal resolutions: form 1x1 to ½ x ½
Spatial resolution and NRT Daily Time Series available
○ API service (data order using URL) – allows for data to be
repeatedly requested using a script or form within our Data
Access Viewer.
