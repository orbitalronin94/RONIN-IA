RFMG Overview

Antennas placed in the tank measure the RF spectrum, which changes with fill level since the dielectric fluid (e) slows the speed of light
The basis of the RFMG is that these changes can be accurately predicted via RF/fluid simulations (e.g., Comsol or CST Studio)
NESC-RP-20-01603 page 50, the NASA Engineering and Safety Center (NESC) identified an area of complex development for RFMG to be “Generation of simulations for all fluid configurations expected during gauging operations”.

Data Analysis 
 Data is generated through “sweeps” during which the antenna emits a range of signals, from lower to higher frequencies, then measures the response
 Dips in response frequencies occur at resonant frequencies based on the tank dimensions and the fluid
 By tracking the resonant frequencies (also referred to as peaks or eigenfrequencies), the entire sweep can be reduced into a few dozen datapoints

Methodology
Original (GRC)
RFMG analysis software finds the peaks, compares the frequencies to a database of simulations, and returns the best match %fill-level information
This is a “bucket” methodology while automated, looks for nearest neighbor matches
Low computational need but large amount of data
Deterministic
Machine Learning (ML) technique
Let the computer learn from the simulation results
Simulations already being run
Interpolation between simulations
Higher computational load, but lower memory need
Non-deterministic (Statistical)
