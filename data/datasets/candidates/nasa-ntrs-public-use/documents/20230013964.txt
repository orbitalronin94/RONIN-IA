<p>Context
• Developed on NASA Goddard Internal Research funding (IRAD)
</p>
<p>• Goal: create and infuse a broadly applicable process to rapidly develop 
lightweight spaceflight structures
</p>
<p>• Method: build and test parts for diverse NASA applications
</p>
<p>• Status: development of typical metallic structures now automated
• Requirements➡parts for fab in 1-2 days(!)
</p>
<p>• Demonstrated by test 
</p>
<p>• Being applied to NASA missions
</p>
<p>• Goals of this presentation
• Share lessons learned about practical implementation of Generative AI 
</p>
<p>• Enable products to improve the mass/stiffness/strength of structures by 2x-4x 
while reducing development time/cost by ~10x
</p>
<p>• Engage the Generative AI community
</p>
<p>"Not every change is an improvement, but every improvement is a change" 2</p>

<p>Evolved Structures: Prompt Engineering for Structures
(1) Create a prompt to digitally encode structure requirements into software
</p>
<p>• Follow written Evolved Structures Guide for NASA applications
</p>
<p>(2) Use Generative Design AI to evolve optimal designs meeting requirements 
• Using COTS software adapted for GSFC needs
</p>
<p>(3) Fabricate parts directly from Generative Design output using Digital 
Manufacturing (software + robots)
• Using industrial processes such as automated CNC and Additive Manufacturing (AM)
</p>

<p>Application Example: EXCITE Tip/Tilt Bracket
• Mission: Analyze atmospheres of exoplanets
</p>
<p>• Goal: Mount Tip/Tilt mirror assembly to the back 
of the Telescope (PI: Peter Nagler)
</p>
<p>• Interfaces: Bolt pattern on Tip/Tilt stage and bolt 
pattern on Telescope. Avoid Tip/Tilt assembly 
volume and optical path.
</p>
<p>• Loads: 10g vertical (x) 3g lateral(y and z) applied 
to Tip/tilt stage center of gravity (1.35 kg mass)
</p>
<p>• Modes: &gt;100 Hz per standard practices and to 
avoid cryo-cooler excitation
</p>
<p>• Bracket mass target: 0.2 kg

<p>How is this possible?
• Generative Design and Digital Manufacturing leverage 
</p>
<p>the massive advances in Information Technology
• Pro/Engineer (e.g., Creo) released 1987
• NASTRAN released 1968
• Computing power has increased &gt;10,000x since 1990!
</p>
<p>• Enables a step-change in Computer Aided Engineering (CAE) 
capability
</p>
<p>• Cloud computing allows practically unlimited compute for FEA
</p>
<p>• Generative Design can be considered an abstraction 
layer on top of:
• Computer Aided Design (CAD)
• Finite Element Analysis (FEA) i.e., simulation
• Design for Manufacturing (DfM)
</p>
<p>Enable more science per dollar by reducing the development 
time/cost and increasing the performance of spaceflight structures.
</p>

<p>Digital Manufacturing
• Manufacturing processes that can make parts from 
</p>
<p>CAD files with minimal human intervention
• Software creates machine code (e.g., gcode) from CAD
• Robot runs the code and makes the part
</p>
<p>• Digital Manufacturing ≠ Additive Manufacturing
</p>
<p>• Automated CNC 
• Computer Aided Manufacturing (CAM) creates gcode from 
</p>
<p>CAD with some human input
• CNC robot runs the gcode
• Exception: Protolabs – automated machine shop
</p>
<p>• 500+ HaaS CNC machines and no traditional machinists
</p>
<p>• Additive Manufacturing (AM, 3D printing)
• Slicer software generates gcode from CAD
• AM robot runs the machine code – e.g. L-PBF
• Post-process machining, heat treatment, support removal
</p>

<p>Pitfalls and Barriers to Adoption
• Skills gap: Design, Analysis, AND Manufacturing skills required
</p>
<p>• Currently stove-piped into different organizations
• Generalist, not specialist level skills required
• Achieve through training
• May produce “10x engineers”
</p>
<p>• Cultural inertia: general resistance to change
• The parts look weird and alien
</p>
<p>• Get feedback and buy in from stakeholders
• Build, test, and fly lots of hardware
</p>
<p>• Fear of being replaced by AI
• Encourage win-win mentality: achieve more
• Encourage growth mindset: fun to learn new tools!
</p>
<p>• GiGo (Garbage in / Garbage out): need to get the requirements right
• Also, a problem for human designs: no more robust against unplanned loads
• Human intuition: from a lifetime of training, we know what “looks right”
</p>
