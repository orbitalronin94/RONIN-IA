MOTIVATION
	
In	Langley	NASA,	Clouds	and	the	Earth’s	Radiant	Energy	System	(CERES)	and	Moderate	Resolution	Imaging	Spectroradiometer	(MODIS)	are	merged	with	Cloud-Aerosol	Lidar	with	Orthogonal	
Polarization	(CALIOP)	on	the	Cloud-Aerosol	Lidar	and	Infrared	Pathfinder	Satellite	Observation	(CALIPSO)	and	CloudSat	Cloud	Profiling	Radar	(CPR).	The	CERES	merged	product	(C3M)	matches	
up	to	three	CALIPSO	footprints	with	each	MODIS	pixel	along	its	ground	track.	It	then	assigns	the	nearest	CloudSat	footprint	to	each	of	those	MODIS	pixels.	The	cloud	properties	from	MODIS,	
retrieved	using	the	CERES	algorithms,	are	included	in	C3M	with	the	matched	CALIPSO	and	CloudSat	products	along	with	radiances	from	18	MODIS	channels.	The	dataset	is	used	to	validate	the	
CERES	retrieved	MODIS	cloud	properties	and	the	computed	TOA	and	surface	flux	difference	using	MODIS	or	CALIOP/CloudSAT	retrieved	clouds.	This	information	is	then	used	to	tune	the	
computed	fluxes	to	match	the	CERES	observed	TOA	flux.	The	capability	of	viewing	C3M	product	on	browsers	will	be	available	on	CERES	ordering	tool	web	site	in	the	future,	
https://ceres.larc.nasa.gov

Even	though	these	instruments	are	all	on	A-Train	satellites,	
they	are	on	different	spacecraft	and	have	different	
resolutions.	In	order	to	compare	data	from	these	
instruments,	preprocessing	the	data	to	align	the	time,	
location	and	to	increase	the	resolutions	is	needed.		An	image	
of	CALIPSO/CloudSAT	is	projected	to	a	2-D	image	for	the	
ease	of	comparison.	
	
The	y-axis	of	images	represents	time.		The	x-axis	of	images	
from	CALIPSO/CloudSAT		indicates	height	from	0.5	meter	
below	sea	level.	Each	pixel	represents	30	meter.			The	x-axis	
of	images	from	CERES	is	footprint	number	from	each	scan	
packet.	The	geospatial	location	of	the	center	line	of	a	CERES	
image	matches	the	location	of	the	y-axis	of	a	CALIPSO/

A	web-based	visualization	tool	
called	3D-CERESVis	is	used	to	
generate	images	and	user

Behind	the	scene,	there	is	a	
cluster	of	Linux	servers	which	
read	data	files,	generate	images	
on	the	fly	in	parallel.		They	can	
generate	large	volumes	of	images	
in	a	short	period	time.	The	
capability	of	creating	images	on	
the	fly	not	only	provides	the	
flexibility	for	users	to	manipulate	
images	and	save	disk	space.	
	
Users’	web	browsers	provide	the	
user	interface	by	using	HTML5	
and	JavaScript.	In	order	to	take	
advantage	of	users’	hardware,	
data	are	also	pushed	to	the	
browsers.	Some	simple	
computations	are	done	by	the	
browsers.	An	open	source	
JavaScript	library	called	Cesium	is	
used	to	project	images	on	a

		The	poster	demonstrates	a	new	graphical	3D-interface,	
3D-CERESVis,	that	allows	users	to	view	both	passive	remote	
sensing	satellites	(MODIS	and	CERES)	and	active	satellites	
(CALIPSO	and	CloudSat),	such	that	the	detailed	vertical	
structures	of	cloud	properties	from	CALIPSO	and	CloudSat	
are	displayed	side	by	side	with	horizontally	retrieved	cloud	
properties	from	MODIS	and	CERES.	Similarly,	the	CERES	
computed	profile	fluxes	whether	using	MODIS	or	CALIPSO	
and	CloudSat	clouds	can	also	be	compared.		
3D-CERESVis	is	a	browser-based	visualization	tool	that	
makes	uses	of	techniques	such	as	multiple	synchronized	
cursors	and	a	JavaScript	library,	Cesium.
